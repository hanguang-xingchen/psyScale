# psyScale — 开源心理学多量表评估

> 配置驱动的静态 Web 应用，即开即用，无需后端、无需构建工具。

**在线体验**：<https://hanguang-xingchen.github.io/psyScale/>

> 📢 **项目状态**（2026-10-18）：psyScale 核心功能已开发完成，支持 10 个量表、繁简双语。后续将探索 NT 分支（PyScript 引擎实验）及 Online 版，敬请期待！

## 支持量表

| 量表 | 简介 | 题目数 |
|---|---|---|
| **PHQ-9** | 抑郁症筛查 | 9 |
| **GAD-7** | 广泛性焦虑 | 7 |
| **SCL-90** | 症状自评（10 维度 + 雷达图） | 90 |
| **CES-D** | 抑郁自评量表 | 20 |
| **WHO-5** | 幸福感指数量表 | 5 |
| **K10** | 心理困扰筛查 | 10 |
| **PSS-10** | 压力感知量表 | 10 |
| **SES** | Rosenberg 自尊量表 | 10 |
| **SAS** | 焦虑自评量表 | 20 |
| **SDS** | 抑郁自评量表 | 20 |

## 功能

- 前端即时计分，结果页提供 JSON 报告下载
- 多维度量表支持 SVG 可交互雷达图（SCL-90）
- 配置驱动：新增量表只需添加目录 + 两个配置文件，无需改 JS
- JSON 报告下载，支持历史记录和趋势分析
